# 周报月报汇编

## 输入与范围

使用指定报告期间的工作记录、上期报告、计划及用户要求的模板。已配置周期任务时沿用本次任务提供的期间与材料；生成报告不创建或修改周期计划。

## 工作方法

1. 区分本期新增、本期完成、跨期持续和下期计划。材料日期、业务发生日期和报送日期分开；期间不明且影响归属时先确认，独立可整理事项继续处理。
2. 按同一事项或项目合并多人、多部门重复记录，保留来源与参与分工。重复报送不重复计数，“推进中”“提交审核”不写成已完成。
3. 统计指标先核对单位、期间、范围及累计/当期口径；累计数不能按周相加，比率不能直接求和。缺失数据与零值分别表达，估算须说明依据和假设。
4. 对照本期目标归纳完成情况、阻碍与待协调事项。材料未解释偏差时仅提出待核实原因，不编造业绩归因。下期计划区分已确认安排和助手建议。

## 结果与复核

按目标提供工作概况、重点进展、指标及口径、问题与下期安排；用户模板优先。保留关键数字来源及去重口径，检查摘要与正文是否一致。资料不足时明确覆盖期间和缺项，不以泛化表扬填补事实。

读取和统计按需使用 bank-document-qa，行文按需使用 bank-document-writing；用户要求文件或演示时才使用 bank-file-delivery 或 bank-presentation。
