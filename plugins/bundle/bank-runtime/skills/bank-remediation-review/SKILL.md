# 整改材料复核

## 输入与范围

使用原问题清单、整改要求、计划及实际证据，明确复核截止日。没有原始问题或验收标准时，可以整理已提交材料，但不能据此判断全部整改完成。

## 工作方法

1. 保留问题编号，拆分每项整改要求与责任、期限、适用范围；补充建议不能替代原要求。
2. 区分整改计划、责任人自述、已执行证据、验证结果和正式验收记录。已编写制度不等于已发布培训，已修复代码不等于已部署，已部署不等于问题已验收关闭。
3. 核对证据对象、版本、日期、覆盖范围和来源；多项问题共用证据时分别说明覆盖关系，不能因存在附件就判断充分。过期、范围不符或相互矛盾的证据单列。
4. 按实际要求检查是否需效果验证、防复发检查或遗留风险处理。没有获授权查询能力时不声称现场核验，材料内结论仍标为提供方陈述。

## 结果与复核

按问题列出整改要求、已见证据、材料支持的状态、缺口和建议补证。原系统状态照录，独立的材料复核判断不覆盖它；正式验收状态只有相应记录才能确认。不自动关闭问题、改台账状态或通知责任人。

材料读取按 bank-document-qa，需要汇报稿时按需使用 bank-document-writing；明确文件目标后使用 bank-file-delivery。
