# 采购评审

从采购要求和用户目标提取评审维度。采购横评中，已确认的材料分组代表供应商。保留分组全称和原始材料出处；分组不明或文件内容与分组冲突时标记待核对。

同一家供应商的商务文件和技术文件共同构成一份响应。先按供应商盘点两类材料，再分别做商务对比和技术对比。目录、文件名可作为线索，以正文和对应采购条款确定归类；合册材料可同时为两部分提供依据。采购方的招标文件、需求书及评分办法用作比较基准，不能算作某家供应商的承诺。

- **商务对比**按采购文件实际要求整理报价、税费、付款、交付、质保及商务偏离。例如核对“报价是否包括三年运维”，同时列出金额、服务期限和出处。
- **技术对比**逐条对应需求编号，核对功能与参数、兼容接口、实施及验收条件、技术偏离。区分供应商自述、明确承诺和材料中附具的测试依据。
- **跨文件核对**检查同一供应商两份文件中的共同承诺。例如技术方案承诺三年服务、商务报价仅含一年，应并列引用两处原文，标记需澄清的期限或费用，不能自行选定其中一个值。
- **结果呈现**按“商务对比”“技术对比”分别列出各供应商对同一条要求的响应和证据，再汇总跨文件矛盾与缺口。仅有一类材料时正常比较已有部分，另一部分注明“未找到商务依据”或“未找到技术依据”。用户明确只审一部分时，仅核对该部分。

- 逐家提取与评审要求有关的事实。报价注明币种、单位、是否含税、折扣及报价范围；交付注明起算条件和期限；质保及售后注明范围、期限和响应条件。用户已限定范围时，按指定维度评审。
- 横向汇总前核对各家口径。单价和总价、不同标段、不同服务期限分别列示。换算或复核所得的值注明算式和依据。
- 每项判断关联该供应商的来源。夜间报告使用对应的真实证据编号，报价表尽量定位到工作表和单元格，扫描材料注明页码。
- 每家均交代覆盖情况。分别标明材料未提供、读取失败、不同版本冲突及待业务澄清事项。仅在评审办法明确给出评分标准与权重时计分，并区分材料事实、核算结果和建议。
