# 表格格式契约

适用于已确定的XLSX或CSV文件交付；不代替材料分析，也不增加统计目标。

优先级：首先稳定交付内容完整、可用的文件，其次提升内容组织和呈现质量。基础表格满足用户要求即可交付，不为了美观增加模型调用、复杂结构或反复重试；优先由生成器处理排版和兼容问题。

- XLSX 使用 sheets 数组，每项 name 与 rows 二维数组；headers 可单列提供。所有集合直接传数组，无 item 包装；content 对象不再次序列化成字符串。
- 新建表格中的公式写成 {"formula":"=SUM(B2:B5)"}，仅引用本工作簿已提供范围，支持算术比较和 SUM/AVERAGE/MIN/MAX/COUNT/ROUND/ABS/IF/IFERROR/SUMIF/COUNTIF，可跨表引用。普通等号开头字符串按文本处理；不提供缓存值、外链、宏或未登记函数。新建工作簿重算后才发布；原件局部修订已暂停；历史修订副本仍须按原报告核对计算状态，宽表分页不删内容，极长单元格仍受 Excel 容量约束。

## 场景样式

新建时优先提供整洁精美且适合用途的版本。在当前生成调用中按用户用途选择下表style；尊重明确选择和排除项，不只看标题关键词。省略时生成器稳定使用office，不根据正文或标题猜测风格。无需询问用户颜色，也不因此增加模型调用。

| style | 场景与呈现 |
| --- | --- |
| office | 默认办公：青灰表头、轻底色、清晰列间距 |
| finance | 金融台账、对账、资金与财务：深蓝与浅金、稳重数字区 |
| budget | 预算执行、费用与报销：靛紫层级，突出汇总 |
| analysis | 经营指标、业绩对比：蓝青配色，突出已有公式结果 |
| tracker | 任务、整改与进度跟踪：石墨与琥珀，强调记录层次 |

场景内容按实际材料组织：金融台账可保留业务编号、期间、金额与状态；预算表可对照已有预算、实际与差额；经营分析可按已有期间或机构列示指标；任务表可列事项、负责人、期限与状态。缺少的数据不补造，只有需要且有依据时才增加计算列。

样式只改变呈现，不添加数据、业务判断、合计、币种、比例换算或额外工作表。按实际用途组织内容；无需照抄模板列名。程序保留A1表头和原公式地址，不插入装饰行；已有合计/小计行可强调。当前不是任意模板文件套用或自由颜色接口，不能发送任意样式字段。

## 内容组织与可读性

按用户用途确定列和工作表：台账保留记录标识、事实和实际状态；统计表说明期间、范围、单位与计算口径；确需汇总时，可将明细与汇总分表并用受支持公式关联。简单清单不强制增加摘要页、说明页或图表，不为凑结构虚构数据、日期、负责人或结论。

金额、数量等可计算值使用数值；账号、编码、前导零及长数字标识使用字符串。零、空值和未取得数据分别处理，未取得数据不补成0；日期和单位保持用户口径。比例应明确使用小数还是百分数及分母范围，不能仅凭列名猜测或混用。表头只出现一次，数据区域不插入装饰标题或重复合计。合计和明细一致，避免将合计行再次纳入汇总。

生成器统一设置中文字体、表头、筛选、冻结、列宽、行高和打印页码；不传当前契约未支持的样式、合并单元格、图表或任意格式字段。仅因样式一般、缺少非关键说明或没有图表，不判定文件交付失败。长文本未超过单元格容量但超过显示行高时，保留完整值并加批注说明可在编辑栏查看，不因此要求模型删内容重试。

## 公式与交付核对

需要可编辑计算关系时使用明确的formula对象，不把自行估计的结果写成公式缓存。只有本次工作簿中的实际数据才能作为引用；按业务含义处理分母为零等情况，不能用IFERROR把未知计算错误统一掩盖成0。参数错误按工具诊断修正，权限或不可重试错误仍遵循主文。

生成器核对提交稿与实际文件中的工作表、单元格类型、值及公式，重算只写回已验证缓存并保留原布局。正常空字符串结果、合法公式写法变化、无内容格式区域不构成失败；损坏文件、数据或公式被改变、真实计算错误不能冒充成功。该检查不核实源数据真实性或业务分析结论。工具发布成功后核对真实成果引用；未实际打开或查看渲染结果时，不声称已完成视觉验收。

生成 Excel：金额为数值，表头只出现一次，不把汇总示例当真实数据。

```json
{"artifact_type":"xlsx","title":"汇总结构示例","output_name":"汇总结构示例.xlsx","content":{"sheets":[{"name":"结构示例","headers":["网点","金额（万元）"],"rows":[["示例网点A",100],["示例网点B",200],["示例合计",300]]}]}}
```

需要跨表可编辑汇总时的完整示例（全部为示例数据，实际使用已确认材料）：

```json
{"artifact_type":"xlsx","title":"明细与汇总示例","output_name":"明细与汇总示例.xlsx","content":{"sheets":[{"name":"明细","rows":[["编号","金额（万元）"],["0001",100],["0002",200]]},{"name":"汇总","rows":[["指标","金额（万元）"],["合计",{"formula":"=SUM('明细'!B2:B3)"}]]}]}}
```

## 已有Excel的修改建议

所有 Office 文件的保留原格式局部修订已暂停，包括上传附件、个人文件及平台生成成果。这是内部能力边界，不向用户说“暂停局部修订”。对用户说明：“我可以提供修改位置和替换内容，方便你在 Office/WPS 中编辑；如果接受重新排版，也可以生成完整新稿。”只有实际尝试未交付时才说明“这次没有生成修订文件，原文件保持不变”。用户要求改标题、文字、单元格或公式时，先说明当前不能直接交付保格式修订文件；依据实际读取范围提供“位置—原内容—建议内容”，由用户在 Office/WPS 中编辑。不得继续提交局部修订，也不改用脚本、转换副本或其他工具绕过。只有用户明确接受重新排版和完整新稿时，才进入重新生成；“只改一处、其他不变”不等于接受重建。

建议公式与普通文本必须明确区分；不得把等号开头的文本当成已经写入公式。分析既有公式不受本次暂停影响，计算结果是否已核验以实际读取和计算证据为准。历史修订副本若提示打开后重算或刷新，仍须保留这些限制，不宣称已验证。

## 完整重建已有成果

仅在用户要求重新组织或重新排版、且实际取得完整支持内容时，使用原完整content修订方式；它会按生成模板重建，不保留任意原件对象。不能将局部修订失败静默改为此方式。以下示例为已接受的完整重建，显式传revision_mode=rebuild，真实使用须替换成果编号：

```json
{"source_generated_file_id":"generated_example_only","instructions":"按新布局重建明细与汇总，将0001金额改为120","output_name":"明细与汇总重建示例.xlsx","content":{"style":"finance","sheets":[{"name":"明细","rows":[["编号","金额（万元）"],["0001",120],["0002",200]]},{"name":"汇总","rows":[["指标","金额（万元）"],["合计",{"formula":"=SUM('明细'!B2:B3)"}]]}]},"revision_mode":"rebuild"}
```

## CSV

使用artifact_type=csv，content为columns字符串数组及rows二维数组，不传CSV源码或再次编码的JSON字符串。金额保留数值类型，表头只出现一次；不要把示例值当作用户数据。

content可选options：encoding仅utf-8或utf-8-sig，delimiter仅逗号、分号或制表符，line_ending仅CRLF或LF。不指定时保持UTF-8、逗号和CRLF；仅按用户要求或明确的接收系统约定选择，不声称自动保留上传文件的编码。尚不支持GBK等其它编码。选项不影响公式注入防护。

```json
{"artifact_type":"csv","title":"示例数据","output_name":"示例数据.csv","content":{"columns":["项目","数量"],"rows":[["示例",1]]}}
```

## 已有文件转换

CSV、XLS的不支持或转换提示以工具实际结果为准，说明原因、可行下一步、原件是否保留和最终格式，不让用户填写内部参数。上传CSV暂不支持直接局部修订；可以完整读取后生成CSV新副本，但不能用已读片段替代全量，也不能声称保留了原编码、分隔符或表示形式。CSV不保存字体、颜色或列宽，导入或重建时关注前导零及长账号。

XLS不能直接修订或交付XLS；有权限且转换能力可用时可转XLSX供读取分析，保留原件；转换不恢复局部修订能力。用户明确接受重新组织并完整生成新表后，才另行生成XLSX新稿。先向用户说明输出格式及复杂格式、公式、对象可能存在差异；若用户明确必须保留XLS，则说明当前无法完成，不擅自换格式。工具提示环境缺少转换能力时，说明可用Excel/WPS另存为XLSX后上传或联系管理员启用，不重复提交相同操作。

工具返回conversion_notice时在交付说明中保留其必要限制，文件卡片也会显示。转换成功仅表示转换副本已生成，不能声称已完成后续修订或验证了格式、公式、对象完全一致；存在对象静态化或读取缺口时一并说明。purpose=read的内部转换不是用户可下载成果，不报已交付。

将上传的旧版 Excel 转为可读取的 XLSX。

```json
{"source_type":"session_file","source_id":"uploaded_xls_example_only","target_format":"xlsx","purpose":"read","output_name":"转换示例.xlsx"}
```
