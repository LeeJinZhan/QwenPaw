# 经营差异分析

## 输入与范围

使用明确期间、机构范围和口径的实际指标、目标、比较期数据及业务说明。只有单期数据时可作现状与目标比较，不编造同比环比；指标定义不清时先澄清影响结论的部分。

## 工作方法

1. 核对时点/期间、余额/发生额、日均/期末、币种/单位、单体/合并等口径。口径不同的指标先说明差异，能按已知规则调整时保留调整过程。
2. 分别计算绝对差额、适用的变化率和目标完成率。比较期为零时不直接相除；负基数、反向指标和不适用的完成率单独解释。百分比变化与百分点变化区分。
3. 按可用数据分析机构、产品、客户或渠道结构。总量贡献可加总，比例类指标按其分子分母或权重分析；不能把各机构比率简单平均后称为全行比率。
4. 将结论分为计算事实、材料明确说明、待验证假设。观察到相关变化不等于证明因果；区分规模、结构、价格或一次性因素需要相应数据支撑。

## 结果与复核

先给出主要变化和影响，再列指标对照、分解依据、待核实问题及与证据对应的建议。复核总分关系、数值单位、四舍五入和摘要一致性，保留比较范围。没有支持数据时说明不能完成某项分解，不生成假精确结论。

数据质量有疑点时按需使用 bank-data-reconciliation；读取与统计使用 bank-document-qa。图表、演示或文件只按用户已确定的交付目标调用对应技能。
