# 表格数据核对

## 输入与范围

明确核对对象、期间、业务键、字段定义、单位及允许差异。按当前授权的文件读取与计算能力处理数据；样本、预览行或缺页不能代表全量结果。

## 工作方法

1. 盘点工作表和实际读取范围，保留原值与定位。统一可比较的日期、单位、币种和字段表示；未经依据不补汇率或自动将空值转零，账户与编号的前导零不能丢失。
2. 确认一对一、一对多或汇总关系。先报告业务键重复，再按明确规则匹配；多对多联接不能静默放大金额或条数。无唯一键时说明匹配方法及不确定性。
3. 核对字段、行数、金额和汇总勾稽关系，区分缺记录、重复、值不同、无法匹配及口径不一致。金额遵循来源精度，容差须有用户或业务规则依据；无依据时列原始差额，不自设“可忽略”阈值。
4. 按授权工具的实际结果计算，保留公式或聚合逻辑及来源行/单元格。读取不完整时可交付已覆盖范围的差异，不宣称全量一致。

## 结果与复核

输出核对范围与口径、总量核对、差异明细和未解决项。检查“已匹配、未匹配、重复/待处理”等分类是否与统计口径一致，避免重复累计。默认给出修改建议，不覆盖原表、不回写业务系统；用户明确要求修订文件时保留修改依据和原始值。

资料读取及受控计算方法按 bank-document-qa；要求文件成果时按 bank-file-delivery，核对方法不授予额外数据或执行权限。
