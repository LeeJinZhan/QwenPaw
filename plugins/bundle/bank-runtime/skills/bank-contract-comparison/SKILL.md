# 合同条款对照

## 输入与范围

明确合同主体、待审版本、对照基准及附件范围。只提供一份合同，可提取条款与内部一致性问题，但不能称为完成两版比较。法律或本行制度判断需取得适用依据，不能凭常识认定条款效力。

## 工作方法

1. 按任务核对标的、数量、费用及税费、付款触发条件、期限、交付与验收、服务与质保、变更退出、违约责任及数据处理等相关条款。
2. 将合同条款与明确的需求、报价或承诺逐项关联；区分文件出现的内容与已签署或被合同明确纳入的约定，不能把未采纳的投标表述视为当然生效的合同义务。
3. 识别缺失、冲突、模糊、条件变化和责任不对等，保留两侧原文出处。期限起算点、费用覆盖范围、自动续期和验收条件分别核对。
4. 有明确优先顺序条款时按其解释文件关系；没有时列出冲突和需确认的选择，不自行确定哪份文件优先。

## 结果与复核

给出条款对照、履约事项、待澄清问题；用户要求修改时提供建议文本，并区分原约定与建议。关注程度依据实际影响说明，不机械套用无来源的风险分值。分析不替代法务结论、审批或签署，不代表合同已生效。

依据检索与读取按 bank-document-qa，文字检查按需使用 bank-document-review；要求修订稿或其他文件成果时使用 bank-file-delivery。
