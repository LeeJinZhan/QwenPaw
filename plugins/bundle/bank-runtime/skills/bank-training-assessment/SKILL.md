# 培训题库生成

## 输入与范围

明确培训对象、学习目标、适用资料版本以及已提出的题型、数量和难度。信息足够时直接生成，未限定题量时选择适合当前任务的规模并说明；不把题库任务扩成考试发布或人员评价。

## 工作方法

1. 将题目分布对应到关键知识、适用条件和操作判断，避免仅从同一段落反复换词出题。重要的例外和权限边界可用场景题考查。
2. 题干写明决定答案所必需的条件，选项保持同一判断维度；单选需有唯一可支持答案，多选需明确规则，主观题列评分要点与可接受的替代表述。
3. 每题答案关联实际条款或材料位置，并说明推理。资料存在冲突、过期或无法支持唯一答案时修改题目或标为待确认，不靠编造规定补全答案。
4. 自拟案例明确为教学示例，使用虚构且最小必要的信息，不挪用真实客户信息。区分制度规定、案例假设和教学建议。

## 结果与复核

按请求给出题目和答案解析；需要学员版和讲师版时分开，检查学员版不泄露答案。复核题量、重复题、正确选项分布、题干与答案一致性及版本依据。课程提纲或课件只有在目标包含时生成，不声称已完成培训或形成考试结果。

依据读取按 bank-document-qa；需要课件或文件时分别使用 bank-presentation、bank-file-delivery。
